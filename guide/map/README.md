# Карта экологии города

Приложение показывает **экологическую карту** вашего города.
На карте находят своё отображение следующие возможные нарушения:

- несанкционированные свалки;
- очаги пожаров;
- загрязнения водных объектов и др.

## Что означают цвета значка нарушения

- зелёный — нарушение не является критичным, приоритет **низкий**;
- жёлтый — нарушение нуждается в скорой ликвидации, приоритет **средний**;
- красный — нарушение требуется устранить в срочном порядке, приоритет **высокий**.
